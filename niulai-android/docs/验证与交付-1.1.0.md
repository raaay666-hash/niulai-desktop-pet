## 变更

完整界面与原生兼容界面均采用灰白卡片、蓝色操作按钮，重新安排字号、间距和信息层级；使用线条图标，保留深浅主题。去掉装饰性英文和口号式文案，统一功能名称。Windows 图标及 2D 牛保留。

桌宠改用原生 View、位图和 MediaPlayer，不依赖 WebView。完整主界面支持旧 Chromium 必要的 API；缺少内核或加载失败时进入原生兼容界面。两种界面共享本机保存的自选和持仓。修复旧内核绘制黑块、系统栏与键盘边距、悬浮授权返回流程，以及已有桌面卡片更新后的颜色。

## 适配范围

Android 8–11 以基本可用为目标，适配重心放在 Android 12–16。优先小米、直接支持 APK 的华为，再覆盖其他主流安卓厂商。目前没有 Android 12–14 或小米、华为等实体机验收，也未验证长期保活、耗电、真实扬声器与震动。

专用外屏、铰链区域和摄像头旁副屏仍需厂商接口、固件准入与实机验证。窄屏重排和入口声明不能替代这些条件。不制作鸿蒙原生 HAP，不保证 HarmonyOS 5+ 兼容容器。测试只在独立 QA 虚拟设备进行；原有 MuMu 实例 0、1 未操作。
