# 牛来盯盘 · 手机桌宠、叠放与屏幕适配

版本：1.2.0。最低 Android 8.0（API 26），以悬浮桌宠为主要入口。只做安卓及仍直接兼容安卓的华为系统，不做鸿蒙原生版。1.2.0 增加行情、时段和点击互动共 21 种 2D 动作，详见 [动作设计](动作设计-1.2.0.md)。

适配优先级：Android 8–11 保证基础功能的兼容路径，开发和验收重心放在 Android 12–16；厂商先小米 / REDMI 和仍直接支持 APK 的华为，再覆盖荣耀、OPPO / 一加 / 真我、vivo / iQOO、三星。已运行验证的版本见交付记录，优先级不代表已经取得对应品牌实机验收。

## 已落地的场景

| 场景 | 功能与默认行为 |
| --- | --- |
| 静音 | 关闭声音和震动，30 秒刷新，保留轻微 2D 动作，隐藏持仓金额；桌宠可缩小以减少遮挡。 |
| 通勤 | 30 秒刷新，显示行情场景，静音、金额隐藏；窄外屏只保留牛、价格、涨跌与状态。 |
| 标准 | 主动点击才发声，10 秒刷新，可轻震；桌宠可拖到桌面边角，悬浮于其他普通应用上方。 |
| 省电 | 关闭连续动作、声音和震动，30 秒刷新；熄屏和锁屏时停止轮询。 |
| 大屏盯盘 | 宽窗口将牛与当前行情放左侧、自选和持仓放右侧；分屏变窄时回到单栏。选择的股票、持仓和输入不因 CSS 重排丢失。 |
| 休息 | 首页休息卡提供 20 秒倒计时，不播放提示音。 |
| 桌面快照 | 标准安卓组件内四卡切换；用时间戳区分快照与实时取数，点击直达应用刷新。默认不露持仓金额。 |

首页的横滑叠放交互在应用内完成；系统桌面组件使用 RemoteViews 的原生按钮切换四个场景。第三方软件不能保证替换所有厂商的系统桌面叠放机制。

完整界面以灰白卡片、蓝色按钮和线条图标呈现，支持深浅主题。功能名称统一为「桌宠 / 行情 / 持仓 / 休息」，提示直接描述操作与数据状态。原生兼容界面采用相同配色与卡片结构。

桌宠由 Android 原生 View、位图与 MediaPlayer 实现，不依赖浏览器内核。完整主界面使用本地 WebView；缺少可用内核或加载失败时使用原生兼容界面，也可在「手机设置」手动选择。兼容界面提供行情、自选、持仓、搜索和桌宠管理，但没有横滑场景和外屏预览；保存数据可以在两种界面间继续使用。

## 适配层次与边界

| 品牌 / 屏幕 | 本版实现 | 仍需验证或外部条件 |
| --- | --- | --- |
| 小米 / REDMI / POCO | 标准悬浮桌宠、前台运行通知、标准桌面组件、按品牌显示后台与悬浮权限说明。 | MIUI / HyperOS 不同版本的保活策略、长时间运行、电池消耗需实体机验证。 |
| Xiaomi MIX Fold 等大折 | 可调整窗口、尺寸变化连续性声明、单栏/双栏、坐标收敛、摄像头安全边距。 | 实际折叠切屏与半折铰链姿态未测；本版没有 Jetpack WindowManager 的铰链分隔位置检测，不声称已完成双屏铰链避让认证。 |
| 小米 Flip 外屏 | 独立 `miui.fliphome.default` 入口、`miui.supportFlipFullScreen` 基础模式、窄屏精简 UI、系统安全区域，展开后可恢复完整布局。 | 外屏入口的展示和连续性可能受固件或厂商名单控制；未申请厂商接入或实机认证。未自动执行开发者 ADB 白名单命令。 |
| 摄像头旁背部副屏 | 设计为牛头像 + 单只行情 + 获取时间，持仓默认隐藏；提供可检查的小屏预览。 | 背部副屏与折叠外屏不是同一接口；系统未开放第三方应用的机型，本版不能在该屏强制运行。 |
| 华为 EMUI / 安卓兼容 HarmonyOS 4.x 等 | 安卓悬浮窗与组件、后台活动/应用启动管理指引、窗口重排；不依赖 GMS。 | 需确认具体系统直接支持 APK；安卓组件不等同华为原生服务卡片。华为实际 Launcher 是否列出/固定组件待测。 |
| HarmonyOS 5+ 原生或兼容容器 | 不在本次支持范围。 | 不因兼容容器能装某些 APK，就推断桌宠跨应用悬浮和组件可用。 |
| 荣耀 | 标准功能及 MagicOS 后台权限指引。 | 机型省电策略与折叠外屏需实测。 |
| OPPO / 一加 / 真我 | 标准功能、ColorOS 等的悬浮与电池指引、窗口尺寸自适应。 | Flip 外屏应用卡片有厂商开放范围，未宣称加入该范围。 |
| vivo / iQOO | 标准功能、OriginOS / Funtouch 的后台限制指引、窗口自适应。 | 外屏应用支持与长时间保活待实测。 |
| 三星 Flip | 额外的官方 `sub_screen` 外屏组件声明，默认隐藏持仓金额。 | 固件是否允许添加、摄像头附近安全区与实体设备验收待测。 |

不能将浏览器改窗口大小等同于厂商认证。已验证 280×512、320×740、360×800、390×844、430×932、844×390、720×820、1000×760 CSS 像素的排版与弹层边界；不是对应品牌的实体机列表。

1.1.0 已在独立 SDK 虚拟设备上验证 Android 8 无 WebView 的原生界面、Android 8 Chromium 69 的完整界面，以及 Android 16 WebView 133 的完整界面。系统栏和键盘区域由原生容器留出空间，旧内核使用必要的浏览器 API 兼容补充。具体运行结果见本版交付记录；这些结果不等于所有 Android ROM 均通过验收。

## 生命周期与隐私

桌宠需要系统悬浮窗授权。Android 13+ 通知申请只在用户点击开启桌宠时出现，拒绝通知不会偷偷要求其他权限；系统仍可在任务管理中显示前台服务。本版不申请无障碍、读取屏幕、读取通讯录、全盘文件访问或开机自启。

锁屏/熄屏隐藏桌宠、停止请求与音频；解锁恢复。关闭桌宠会移除窗口并停止前台服务。无自动重启机制。系统可能在安全页面强制屏蔽悬浮窗，应用遵从该策略。

主屏组件默认隐藏金额，外屏组件强制隐藏。公开行情快照包含获取时间；失去网络时不伪造新报价。成本、股数不发给行情接口。
