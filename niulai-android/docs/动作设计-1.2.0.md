# 牛来 2D 动作 · 1.2.0

保留原有牛形象，通过头部、前蹄的分区变形和眨眼表现状态，不引入 3D 引擎。首页与原生悬浮桌宠使用同一份动作参数、同一套状态规则。共 21 种：17 种行情/时段状态，4 种主动互动。

## 状态与动作

| 状态 | 动作 | 判断依据 |
| --- | --- | --- |
| 上涨 / 下跌 | 抬头点头 / 低头轻晃 | 当日涨跌幅超过 ±0.15%，尚未形成其他短时状态。 |
| 明显上涨 / 明显下跌 | 抬起前蹄 / 趴低 | 当日涨跌幅达到 ±3%。这是动作阈值，不等于涨跌停。 |
| 昨收附近 | 安静趴着 | 当日涨跌幅在 ±0.15% 内。仅凭此条件不判断横盘。 |
| 窄幅波动 | 左右看看 | 至少三次获取、跨度至少 20 秒，窗口内最高/最低价差不超过 0.12%。 |
| 短时上行 / 短时回落 | 轻跃站稳 / 缩一下再探头 | 最近 90 秒内、至少两次获取且跨度至少 5 秒，相对窗口首价变化达到 ±0.6%。 |
| 低位回升 | 从趴低慢慢抬头 | 至少三次获取、跨度至少 10 秒；窗口内先较首价回落 0.5%，再较窗口低价回升 0.45%。 |
| 高位回落 | 侧头往下看 | 至少三次获取、跨度至少 10 秒；窗口内先较首价上行 0.5%，再较窗口高价回落 0.45%。 |
| 开盘前 / 开盘时段 | 伸展前蹄 / 探头 | 对应市场工作日 09:15–09:30 / 09:30–09:33 的常规时钟。 |
| 午间休市 | 眯眼打盹 | A 股与港股各自常规午休时段。美股无此分支。 |
| 常规时段外 / 周末休市 | 放松趴着 / 歪头睡觉 | 各市场当地时区，包含美股夏令时转换。 |
| 等待行情 / 更新延迟 | 抬头张望 / 歪头等候 | 交易时段无有效数据，或请求失败、数据获取时间超过阈值。 |
| 招手 / 点头 / 开心 / 别挠了 | 抬单蹄 / 点两下 / 轻跃 / 歪头躲一下 | 主动点击或动作预览；不改变行情。连续点击桌宠可触发躲闪。 |

## 调度

- 获取失败优先显示更新延迟；休市状态优先于昨天留下的涨跌幅。常规时段内依次判断回升/回落、短时变化、窄幅变化、当日涨跌幅。
- 行情动作至少保持 8 秒，减少阈值附近频繁切换；断网和时段变化立即响应。切换股票、跨日、跨交易阶段时清空短期历史，超过 90 秒的样本移出。
- 动作进入时才播放轻跃、缩身等短动作；持续状态以轻微抬头、前蹄移动和眨眼为主。报价不断刷新不会反复重播同一短动作。
- 原生桌宠约 24 FPS；网页画布最高约 24 FPS。动画关闭后保持静态姿态，不继续重绘和播放特效；隐藏页面、熄屏和锁屏暂停。行情动作不自动播放声音或震动，音震只由主动点击触发。
- 首页提供招手、点头和「动作预览」。预览窗口明确标注不改变行情；开启桌宠后还可在悬浮牛上预览 6 秒，随后恢复行情动作。

## 数据边界

短时状态来自本机获取的报价样本，不是逐笔行情。没有积累足够样本时，不显示快速变化、回升或回落。源未提供有效成交时间时，无法证明报价为最新成交；这些动作描述已获取数据，不应当作实时告警或交易信号。

交易时段按常规周历估算，尚未接入交易所节假日、临时休市、停牌和不同证券的涨跌停规则。因此不标注「涨停」「跌停」「停牌」，也不显示买卖建议。3% 等阈值用于区分动作强度，并非对所有市场具有相同风险含义。

## 验证

`tests/motion.test.mjs` 同时调用网页逻辑和 JVM 中的原生逻辑，核对时区/夏令时、历史变化、切换股票、断网、过期、冷却和网格不翻折。`scripts/verify-motions.mjs` 检查实际页面动作切换、21 种预览、静止模式与窄/横/宽窗口，并产出动作图和预览帧。

预览使用确定的测试数据，明确展示为动作演示；原生生命周期检查使用独立 Android 15、16 测试设备。品牌实体机、长时间耗电和实际厂商外屏仍需后续验收。
