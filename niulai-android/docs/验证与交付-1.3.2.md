# 牛来盯盘 Android 1.3.2

## 本版内容

- 15 组完整角色逐帧动画，每组 24 帧，覆盖 27 种行情、时段和点击状态。主界面、动作预览、桌宠和微缩牛来共用原画。
- 木鱼单击播放一次敲击。连续点击保留每次计数，密集点击合并动画节拍，最多等待一次后续敲击，避免长时间积压。
- 单次敲击约 400 毫秒，持续快敲约 300 毫秒一轮。红色“牛气➕1 📈”随点击出现，约 720 毫秒淡出。
- 木鱼声音取自官网原音频的 0.245 至 1.055 秒，保留“牛来”语音并处理首尾淡入淡出。成品长 0.81 秒。连续点击时音效间隔至少 480 毫秒，同时播放最多两路。
- 前摄贴合读取当前显示开孔和屏幕边界，提供居中、侧边、宽刘海、横屏与小窗口布局。系统识别异常时可手动设置开孔位置、宽高和偏移。
- 前摄区域交互通过用户开启的“牛来前摄交互”服务承载，支持轻触展开、左右滑动切换自选、下滑展开、上滑收起和长按打开应用。该服务仅承载牛来自己的控件，配置中读取窗口内容能力为 false。
- 清理官网下载页的口号、装饰标语和重复说明，改为功能、平台及下载信息。反馈窗口使用直接的表单用语。安卓端同步修正文案与特效设置名称。

## 行情与动作

以下为常规时段内的日涨跌幅基础规则。时段、数据延迟、短时变化和冷却规则会优先参与判断。

| 日涨跌幅 | 动作 |
| --- | --- |
| 大于或等于 +5% | 举蹄庆祝 |
| +2% 至 +5% 之间 | 拍蹄鼓掌 |
| 大于 +0.15% 且小于 +2% | 竖蹄点头 |
| -0.15% 至 +0.15%，含边界 | 挠头 |
| 大于 -1% 且小于 -0.15% | 托腮 |
| 大于 -3% 且小于或等于 -1% | 上香 |
| 大于 -5% 且小于或等于 -3% | 捂眼 |
| 小于或等于 -5% | 低头休息 |

## 安装与设置

1. 安装同目录的 APK，可覆盖使用相同签名的旧版。
2. 在设置的“桌宠”中开启悬浮桌宠，并按系统提示允许悬浮窗。
3. 在“灵动岛”中开启显示。需要贴合前摄时，选择“自动识别开孔”，打开“前摄交互”，再进入系统无障碍设置启用“牛来前摄交互”。
4. 木鱼音效和牛气＋1 动效可在“木鱼”设置中分别开关。
