# 牛来盯盘 Android · 1.4.0

安卓安装版，以 **2D 悬浮桌宠** 为主。应用和桌面图标直接复用 Windows 版 `build/icon.png`；不包含 Three.js、GLB 或 3D 牛。

## 安装与桌宠

安装包位于仓库 `release/android/Niulai-Android-1.4.0.apk`，最低 Android 8.0（API 26）。无需 Google 服务或登录。本版完整界面及原生桌宠在独立 Android 15 / WebView 110 模拟器验证；Android 8 和 16 的既有验证属于历史版本，本版尚未复测。缺少可用 WebView 时自动使用原生兼容界面，桌宠本身不依赖 WebView。

公开下载入口为 https://niulai.raaay.art/download/ ，按页面标注的版本选择。

1.4.0 为 15 组动画加入校色、插帧和 384px 无损分页，覆盖 27 种状态。优化主题、点击反馈、列表刷新和中文输入；原生悬浮层同步美股盘前盘后报价。木鱼、灵动岛和原有自选持仓保留。详细内容见 [三端更新与验收](../docs/三端优化与正式发布-20261114.md)。

设置增加检查更新、更新说明和系统通知入口。打开或返回应用时检查官网正式版本，6 小时内合并自动检查；同一版本成功系统提醒后不重复。Android 13+ 点击开启通知时可请求系统权限，拒绝后仍有软件内提示。先安装本版才具备后续更新提醒；不在应用关闭后即时推送，不自动下载安装。

1. 将 APK 发到安卓手机，打开文件并按系统提示安装。
2. 打开牛来，点击首页「开启桌宠」，在系统页允许「显示在其他应用上层 / 悬浮窗」。Android 13+ 会再询问通知权限，用于显示运行和关闭入口。
3. 回到牛来后，点击「返回桌面」，或直接返回系统桌面。
4. 拖动牛来可挪位置；摸牛播放所选音效（声音默认关闭）。牛上方 `↗` 打开应用，`−` 收起，`+` 展开，`×` 关闭。通知也有「关闭桌宠」。

桌宠采用小范围透明窗口，不创建全屏输入遮罩。位置和收起状态保存在本机；旋转或窗口尺寸改变时限制在屏幕内。锁屏、熄屏隐藏并暂停刷新和声音，解锁恢复。不自启动，不在开机后自动恢复，不在用户关闭后偷偷重启。银行、支付、权限设置等安全页面可由系统主动屏蔽悬浮窗。

## 卡片与场景

- 完整界面首页卡片可横滑或点击「桌宠 / 行情 / 持仓 / 休息」。默认按常规交易时段推荐行情或桌宠，手动切换后一小时内保持选择。
- 「桌面叠放卡片」添加安卓标准小组件；四个场景通过左右箭头切换，点击内容打开应用刷新。能否与其他应用组件组成系统级叠放，由桌面启动器决定。
- 桌面卡片明确标记**快照及获取时间**。应用或桌宠获取行情时更新；桌宠运行时最多约每 30 秒同步卡片，未运行时保留最后快照，点击打开应用更新。不承诺后台小组件秒级刷新。
- 持仓金额默认隐藏；只有主动关闭隐私开关才会在主屏组件显示原币盈亏。三星外屏组件的持仓场景始终隐藏金额。
- 设置中有「静音 / 通勤 / 标准 / 省电」四种手动预设。
- 原生兼容界面保留自选、名称/代码搜索、持仓盈亏、桌宠与组件入口，以及声音、动画、主题、刷新频率设置；不包含完整界面的横滑场景和外屏预览。两种界面共用本机保存的自选与持仓。

## 手机与折叠适配

优先小米、兼容安卓的华为。主页面有品牌识别与权限引导，覆盖小米 / REDMI、华为、荣耀、OPPO / 一加 / 真我、vivo / iQOO 和通用安卓。它不会修改系统省电策略或擅自授予权限。

Android 8–11 以基本可用为目标；适配重点放在 Android 12–16 的系统栏、键盘、通知、前台服务、后台限制与窗口变化。本版运行检查覆盖独立 Android 15 模拟器，其他系统版本与各品牌实体机仍待补充。

窄外屏使用精简的「牛来 + 当前行情」布局，展开大屏支持双栏；旋转、分屏和窗口变化保留自选及持仓。屏幕安全区域避开系统栏和摄像头裁切。已加入小米 Flip 官方外屏入口、连续性声明及三星官方外屏组件元数据，**不代表已获得各厂商外屏白名单或完成实机认证**。摄像头旁的背部副屏如果不向第三方应用开放，普通 APK 不能绕过限制。

华为仅覆盖能直接运行安卓 APK 的 EMUI / HarmonyOS 4.x 等系统，不制作鸿蒙原生 HAP。HarmonyOS 5+ 的兼容容器不纳入支持范围。详见 [适配与场景设计](docs/适配与场景设计.md)。

## 行情与数据

A 股、港股、美股，自选上限 20 只；复用桌面端新浪解析及腾讯备用源。中文名称和代码搜索、持仓成本和股数、今日及累计盈亏、原币单位。公开源可能延迟或中断，源未提供时间时明确说明，取数时间不等于最新成交时间。交易时段按周历估算，不包含交易所节假日与临时停牌日历。

设置、自选和持仓仅保存在本机，卸载会清除。只有查询词和股票代码发送至行情提供方，成本与股数不上网。无券商交易接口，无投资预测或收益保证。

## 构建与验证

Windows、JDK 17+、Node.js 22+、Android SDK platform 35 / build-tools 35。在仓库根运行：

```powershell
npm ci --prefix niulai-android
node --test niulai-android/tests/*.test.mjs
powershell -NoProfile -ExecutionPolicy Bypass -File niulai-android/scripts/build.ps1
```

可通过 `-SdkRoot` 指定 SDK；缺省使用 `ANDROID_HOME` / `ANDROID_SDK_ROOT`，或仓库 `.tools/android-sdk`。使用原生 SDK 的 aapt2、javac、d8、zipalign、apksigner，不依赖 Gradle 或 Android Studio。Windows 构建暂存区为 `%LOCALAPPDATA%/NiulaiAndroidBuild`，用于避免 aapt2 对中文路径的兼容问题。

`.signing/niulai-local.p12` 是首次构建生成并持续复用的本地分发签名，已忽略，不打进交付包。以后更新必须保留同一签名；正式商店分发前应由产品持有人管理签名。也可传入 `-KeyStore` 和 `-KeyAlias`，通过环境变量 `NIULAI_KEY_PASSWORD` 提供密码。

界面测试：`node niulai-android/scripts/verify-ui.mjs`，需要本机 Edge。原生脚本仅允许明确指定的独立 QA 模拟器，见脚本内说明，不可直接对私人手机运行。

本版验证记录与图片见仓库根 `outputs/polish-20261113/android`，详细范围见 [三端更新与验收](../docs/三端优化与正式发布-20261114.md)。小米、华为实体机和实际折叠外屏仍待复测。
