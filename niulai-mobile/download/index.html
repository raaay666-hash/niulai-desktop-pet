总览

查看 A 股、港股和美股的自选行情，记录成本与股数，计算今日和累计盈亏。自选和持仓保存在本机。

手机版

Android
悬浮桌宠
把 2D 牛来放在屏幕上，拖动调整位置，随时收起或展开。
灵动岛
在屏幕上方查看价格和涨跌幅。轻触展开，横滑切换自选，前摄位置可手动校准。
敲木鱼
单击完成一次敲击，连点逐次计数。音效和牛气＋1 动效可分别开关。
桌面卡片
切换桌宠、行情、持仓和休息页面，外观可跟随系统深浅模式。

电脑版

Windows / macOS
桌面看盘
查看 A 股、港股和美股行情。美股区分盘前、常规与盘后，标明对应报价时间。
自有行情源
接入自己的报价接口，设置密钥与字段映射，测试连接后用于各个桌面窗口。
持仓与隐私
填写每股成本和持有股数，查看今日与累计盈亏，也可隐藏持仓金额。
牛来互动
二维桌宠随行情切换动作，支持点击互动和语音。木鱼计数在主面板、桌宠与悬浮窗间共享。
窗口与模式
桌宠、悬浮窗和四场景卡片可独立开启，支持深浅外观、静音、省电及窗口位置记忆。
