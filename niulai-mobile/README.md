# 电子牛来 · 手机版

首页顶栏右侧的电脑下载图标为「下载牛来盯盘桌面端」入口，与左侧设置图标保持视觉平衡。点击进入站内 `/download/` 页面，展示产品介绍、托腮角色与 Windows、Mac Apple 芯片、Mac Intel 芯片三个版本。所有按钮通过同域 `/files/` 地址直接下载，不打开外部发行页面。页面跟随原昼夜主题；离开木鱼页时暂停自动敲击、声音与震动并保存累计。素材仅用于网站，不覆盖桌面软件素材。

`node prepare.mjs` 生成静态页面和 Pages Advanced Mode 下载 Worker；`_routes.json` 将动态处理限制在 `/files/*`。`download-files.json` 记录固定发行文件的大小和 SHA-256，构建时嵌入 Worker。下载按流返回，支持 HEAD 与字节范围，不缓存二进制到木鱼的离线缓存。运行 `node --test scripts/test-download-worker.mjs` 检查传输及异常路径。

公开网页版：**https://niulai.raaay.art/**。独立 Cloudflare Pages 项目 `niulai-muyu`，免登录；2026-10-20 用户已确认在大陆手机网络、不经过代理时可以打开并播放声音。该结果是用户所在网络的实际反馈，不代表所有地区、运营商或未来时刻的可用性承诺。发布与更新说明见 `PUBLIC_DEPLOYMENT.md`。

首页空闲时只显示本轮数量、累计数量和牛来大头，左上角有一个设置入口。白天背景 #E7DFD2，黑夜背景 #302722；文字、图标、设置面板随主题切换。默认跟随系统，也可在设置→外观中手动选择白天或黑夜，选择保存在本机；跟随系统时会即时响应系统外观变化。点击大头播放“牛来”音频并加一，同时短暂出现红色上涨箭头和“牛气➕1”，约 0.9 秒后消失；关闭点击动效时不显示，系统减少动态效果时只显示静态反馈。

所有其他功能放在设置：声音、音量、自动敲击、间隔、点击动效、点击震动、开始新一轮。累计保存在设备中，新一轮和重启只清除本轮。自动敲击启动时会立即敲一下，进入后台自动停止。

点击震动默认开启，在支持 Vibration API 的浏览器上，每次手动点击请求一次 18ms 短震；自动敲击不震动。可关闭且会保存选择，声音、动效与震动各自独立。浏览器不支持该接口时在设置显示提示；系统静音/勿扰、设备硬件或浏览器策略可能影响实际震动。iPhone Safari 网页版不提供此接口，当前不能声称已实现 iPhone 马达反馈；正式原生 iOS 需另接 Capacitor Haptics 等原生接口，并做真机验证。

这是适配 Android 与 iPhone 的 PWA 手机网页应用，不是已签名 APK 或 iOS 原生安装包。Android 可通过 Chrome 的“添加到主屏幕/安装应用”；iPhone 使用 Safari 的“分享→添加到主屏幕→作为网页 App 打开”（具体名称随系统版本变化）。首次加载成功并完成缓存后可离线使用。

源文件没有前端依赖；`node prepare.mjs` 将运行文件复制到 dist/。需要 HTTPS（或本机 localhost）才能启用 Service Worker；从文件管理器直接打开 HTML 不提供离线安装能力。浏览器与各平台安装副本的本地数据可能独立，清理浏览器数据或卸载会移除计数。

头像使用内置 imagegen 从父项目牛来三视图生成；提示词保存在 ../niulai-muyu/assets/head-prompt.txt。声音复用父项目 assets/audio/niulai.mp3。当前没有重新核实这些既有素材的公开发行授权。


## 2026-11-12 逐帧木鱼

在完整牛来仓库的 niulai-mobile 目录运行 node prepare.mjs。构建使用仓库现有的 esbuild，将首页脚本与安卓共享的帧播放逻辑打包到 dist/app.js，并复制木鱼图集和短音效。公开部署使用 dist。
