# 官网「牛气＋1」手绘字样

用户否定了上一版的普通圆角提示。本次从字形本身重新设计，制作并在真实页面比较圆笔、轻圆笔与圆角几何三种处理，最终采用轻圆笔方案。

“牛”“气”的笔画使用手工绘制的贝塞尔路径，统一圆头与圆转角，略微前倾，调整横画的弧度和长短以保留自然手写感。“＋1”单独绘制，按 70% 比例缩小并抬高，形成字样右上方的视觉重音。保持清晰字义，不在字形上附加装饰。

字样采用透明底，手机常规宽度为 136px，矮屏为 118px；颜色继续使用页面现有文字色与强调色。牛角上方保留间距。动效为轻弹、短距离上浮和淡出，结束后清理。连点复用单条提示，不影响逐次计数；关闭动效、系统减少动态效果仍遵循既有设置。

生产文件为 niulai-mobile/tap-wordmark.mjs 和 styles.css，随 app.js 打包。字样不依赖外部字体，缩放时使用矢量笔画；它是特定词组的绘制，不是一套完整字体。缓存版本 niulai-mobile-v25-wordmark，应用安装包、版本号和更新通知清单不变。
