# 官网「牛气＋1」艺术字

本次只调整官网敲木鱼的点击反馈。中文采用有粗细变化的毛笔字形，配合重新绘制的加号、数字 1 和轻扬笔锋；整体略向上倾斜。浅色主题为朱砂红，深色主题为暖杏色。竖屏留出牛角上方空间，较矮的横屏单独调整位置。

字形使用内联 SVG 轮廓，避免点击时加载字体或依赖系统 emoji。中文轮廓来自项目已使用的 Ma Shan Zheng（SIL OFL 1.1），加号、数字、笔锋和组合排版为本次绘制；这是特定词组的艺术字，并非一套完整的新字体。许可证保留在 niulai-mobile/assets/fonts/OFL-MaShanZheng.txt。

源码为 niulai-mobile/rise-lettering.mjs，生成脚本为 niulai-mobile/scripts/build-rise-lettering.py（需要 FontTools）。字样约 1.05 秒轻扬淡出，继续尊重关闭动效与系统减少动态效果设置。原计数、音效、震动和离线播放保持原有行为。

本地四种屏幕/主题组合与 14 项木鱼回归检查通过。网站发布目录为 artifacts/niulai-public-lettering-20261114；最终线上检查与截图保存在 outputs/website-lettering-20261114。软件版本和安装包没有改变，官网更新记录已添加本次改动。
