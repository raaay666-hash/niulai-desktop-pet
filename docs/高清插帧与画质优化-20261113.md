# 电脑版高清插帧与画质优化 · 2026-11-13

本轮包含色闪修复、插帧、画质增强与渲染优化，并继续整合三端交互和更新提醒。电脑版版本为 1.6.0，Android 为 1.4.0，成品集中在 `release/polish-20261113`。此前的 `motion-20261113` 和 `color-20261113` 是中间成品。

## 成品内容

- 15 套动作、27 个状态。原来每套 24 帧、每帧 256×256；高清资源为每帧 512×512，总计 1,176 帧，统一 60 fps 时间基准。木鱼原来 400 毫秒已有 24 帧，保持原帧数；快速点击仍合并节拍，计数规则不变。
- 使用 Real-ESRGAN x2plus 增强原 PNG 帧，神经增强与 Lanczos 基础采样按 55%/45% 混合，以减少过度锐化。模型推断的细节不能视为原素材中真实存在的新细节。
- 使用 RIFE 4.26 推算中间运动，颜色和透明度以同一运动场同时处理。对预乘颜色及 alpha 一起插值，再恢复透明图，避免分别处理轮廓造成黑边。不是简单复制帧或双图透明叠加。
- 增强前、增强后和插帧后稳定毛色及口鼻色，去除原透明区不足 1% 的低透明噪声。最终 78 张帧页使用无损 WebP，避免有损压缩重新引入色差。
- 播放器按 4×4 帧页读取与预加载，页缓存上限四张，避免一次解码整套高清图集。普通角色按 60 fps 预算绘制，微型角色 30 fps；静止画面跳过重复绘制，隐藏窗口暂停。
- 根据 CSS 尺寸和屏幕像素比更新画布，像素比最多 2×、单边最多 1024，使用高质量缩放。没有增加动态打光、曝光或整体缩放，避免重新制造颜色闪动。
- 高清资源不可用时回退到校色后的原动画。AI 推理只发生在制作阶段，不把模型或 Python 环境装进桌面软件。

## 生成与验证

离线脚本：`scripts/build-hq-motion.py`、`scripts/stabilize-hq-motion.py`。运行环境使用现有 `.tools/hunyuan-venv/Scripts/python.exe`，本机 RTX 5070 Ti Laptop GPU。模型使用安全权重加载并严格匹配推理层；RIFE 的教师和训练时间头不参与推理。

来源：

- [RIFE 架构实现与 4.26 权重](https://github.com/Fannovel16/ComfyUI-Frame-Interpolation)，MIT；本地保存原始许可证。上游算法见 [Practical-RIFE](https://github.com/hzwer/Practical-RIFE)。
- [Real-ESRGAN x2plus](https://github.com/xinntao/Real-ESRGAN/releases/tag/v0.2.1)，BSD 3-Clause；本地保存原始许可证。

输入图集、模型和架构摘要见 `outputs/desktop-hq-20261113/generation-all.json`；插帧后校色与最终帧页摘要见同目录 `final-assets.json`。

`scripts/audit-hq-assets.py` 检查每个最终压缩帧的材质颜色中位数、透明角落和主体面积。该颜色指标不是感知 Delta E，不代表运动画面所有像素恒定。`npm run test:hq` 检查全部帧的真实浏览器绘制、跨页访问、缓存、暂停、2× 高分屏、故障回退及一次实时播放采样。最终成品的流程检查和精确安装包摘要统一记录在 `outputs/polish-20261113/delivery.json`。

插帧和增强不能替代重新制作角色骨骼、遮挡关系和原画；大幅度动作的主观自然度仍需用户观看。Windows 安装包未签名，Mac 尚未 Apple 公证。三端构建、测试和官网发布状态以 `outputs/polish-20261113/delivery.json` 为准。Android 使用 384 像素无损分页素材，原生层在后台线程解码，缓存限制为 40 MiB。
