# 牛来盯盘电脑版 1.5.0 设计

## 页面结构

主面板使用侧栏与双栏工作区，默认 1180 × 820，支持缩放窗口，最小 860 × 640。主列展示当前行情、角色、持仓与采样曲线，右列展示自选。

| 页面 | 主要操作 |
| --- | --- |
| 盯盘 | 查看行情、互动、切换股票、调整桌面显示 |
| 自选 | 搜索、切换、编辑持仓、移出自选 |
| 持仓 | 查看原币盈亏、成本与股数，按股票独立编辑 |
| 木鱼 | 点击或空格敲击、管理本轮、开启悬浮木鱼 |
| 设置 | 悬浮窗、桌宠、木鱼、卡片、通用、提醒与记录、关于 |

延续安卓版的灰白卡片、蓝色操作色、线条图标与深浅主题。红色代表上涨，绿色代表下跌。控制界面使用蓝色，角色保留原有金黄色。关闭动作和隐藏页面时停止相关动画刷新。

## 电脑版适配

| 安卓功能 | 电脑版实现 |
| --- | --- |
| 行情与角色首页 | 双栏主面板，自选与持仓同屏 |
| 逐帧动作 | 共用动画数据和帧图，按独立画布播放 |
| 木鱼 | 本机主进程统一计数，支持空格与鼠标 |
| 顶部行情条 | 可拖动悬浮窗，滚轮与左右按钮切换股票 |
| 四场景卡片 | 独立悬浮窗口，标记获取时间 |
| 跨应用桌宠 | 透明置顶小窗口，拖动、收起与关闭 |
| 应用隐藏后继续工作 | 托盘驻留，主进程统一行情轮询 |

电脑版移除前摄校准、手机震动、折叠外屏、安卓悬浮权限和系统小组件申请流程。3D 形态、3D 巡游、模型加载与 Three.js 从当前运行链路和发行文件中移除。

## 交互

- 设置按分类展开，控件调整即时保存。
- 移出自选前确认，存在持仓时明确提示对应记录会清除。
- 所有桌面窗口独立开关，窗口位置自动保存。
- 桌宠可收起为小牛，悬浮窗点击展开，卡片通过四个页签切换。
- 默认持仓隐私开启，主面板与桌面显示保持一致。
- 默认关闭自动“妈妈”音效，开启后的确认、冷却和音量规则见使用说明。

## 数据与运行

主进程负责网络请求、保存、共享计数、窗口生命周期和哭泣触发规则。各窗口读取同一份快照，不单独轮询行情。保存队列确保多个窗口同时敲击时计数连续。

行情曲线使用真实获取的报价样本。断连保留最后报价并标记更新延迟。系统锁屏和睡眠暂停轮询及显示，恢复后重新获取。

发布文件使用明确的文件清单，仅包含当前运行所需脚本、二维帧图、音频、图标和使用说明。旧源码备份位于 `artifacts/desktop-1.5.0-before`。
