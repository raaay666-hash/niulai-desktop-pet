# 官网敲击反馈与产品风格统一

> 历史方案：用户认为圆角提示仍缺少设计感，同日已继续重绘为轻圆笔手写字样。当前方案见《官网手绘字样-20261115.md》，此处保留当时的实施记录。

用户指出旧版毛笔大字与软件整体设计不协调。本次沿用各端共同的无衬线字体、柔和圆角、清楚层级和低干扰反馈原则，在官网使用已有主题变量，而不是将桌面端的蓝灰配色硬搬到暖色页面。

“牛气”使用 14px 常规字重，“+1”使用 16px 中等字重和主题强调色，组合为 92 × 34px 的圆角提示。提示位于牛角上方，约一秒淡入、轻移并淡出；取消书法轮廓、笔锋、随机漂移和旋转。它是界面文字排版调整，不是新造的一套字体。

连续敲击复用同一提示，在已出现后续接可读阶段，避免堆叠或反复淡入。每一次点击仍分别计数；关闭动效后不显示，系统减少动态效果下静态显示并自动清理。计数存储、音效、震动及高清角色播放器保持既有行为。

网站更新记录新增独立的“官网”条目。应用更新清单仍取最近一次应用发行，updates.json 与此前发布逐字节相同，避免将网站外观调整当成应用新版本。缓存升级为 niulai-mobile-v24-feedback。

本地 15 项既有流程及新增反馈回归通过，包含连续点击、减少动态效果、离线播放和计数保存。手机浅色、手机深色、桌面与横屏四种截图检查通过。冻结发布目录为 artifacts/niulai-public-feedback-20261115，共 37 个文件，只有 app.js、styles.css、index.html、sw.js 和更新记录页面发生改变。

正式发布与资源核验结果以 outputs/website-feedback-20261115/delivery.json 和 publication.json 为准。证据目录包含本地与正式站截图。浏览器检查基于 Windows Edge 的视口模拟，不等同于实体手机验收。
