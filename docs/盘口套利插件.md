# 牛来盘口套利插件 0.1.0

## 安装与试用

1. 安装牛来盯盘 1.8.2，并从同一版本的发布页下载 `niulai-orderbook.niulai-plugin.json`。
2. 在牛来左侧打开 **量化插件**，点击 **导入插件**，选择刚下载的 JSON 文件。
3. 选择 **样例回放** 和 **双场所价差**，点击 **开始模拟**。也可以换成 **盘口失衡抢单**。
4. 在结果里查看盘口时间差、模拟成交和取消。用 **导出本轮记录** 保存最近 100 笔已完成的信号及本轮累计统计。

## 实时行情接入

**牛来自有源盘口**支持单标的抢单。先在牛来配置自有源、添加该标的到自选。自有 JSON 快照须提供单位为 `股` 的 `orderBook`、买卖档和独立的 `orderBook.timestamp`。引擎复用既有轮询节奏，只接受连续竞价时段的自有源盘口。

**深度推送（NDJSON）**可用于两种策略。填写 HTTPS 或本机 HTTP 流地址，服务持续返回 UTF-8 文本，每行一份完整盘口 JSON，并以换行结束。建议服务端逐行刷新缓冲区，保持来源与客户端时钟同步。

```json
{"symbol":"DEMO","venue":"VENUE-A","currency":"USD","unit":"share","phase":"continuous","sequence":197,"timestamp":1795401000123,"bids":[{"price":100.00,"size":900}],"asks":[{"price":100.03,"size":200}]}
```

- `symbol`、`currency`、`venue` 与插件设置一致。双场所必须是同一可交割资产、同一币种的两个独立成交场所。各行情商转发的同一交易所报价应使用同一场所标识。
- `timestamp` 是源端的 UTC 毫秒时间戳。每个标的和场所的 `sequence` 递增。只在连续竞价期间标记 `phase` 为 `continuous`。
- 买盘从高价到低价，卖盘从低价到高价，数量为正整数股。每侧使用前 20 个档位。每行最多 64 Ki 字符。

## 模拟成交

盘口抢单用前三档买卖量差和最大买卖价差判断。双场所策略逐档计算给定股数可用的买卖价格，并扣除买卖费率、最低费用和滑点。两个场所分别使用设置里的初始现金和可卖库存。

信号出现后，模拟委托等到设定的延迟过去才检查新盘口。每腿按限价和可见深度整腿成交或取消。模拟已消耗的同价深度会扣减。买入增加持有数量，现有可卖库存随卖出扣减。双腿只有一腿成交时，界面显示剩余敞口对应的持有变化，并暂停本轮模拟。

样例中的标的和场所为合成数据。真实推送只提供模拟依据，排队优先级、未展示深度、市场冲击和券商限制均需要独立验证。本插件运行本地模拟，不连接实盘账户。
