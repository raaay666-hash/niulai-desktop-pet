# 版本更新与发布

正式发布入口为 https://niulai.raaay.art/download/ ，更新记录为 `/download/updates/`，软件读取 `/updates.json`。

1. 更新电脑版和 Android 版本号及 Android versionCode，保留应用 ID、持久签名和本机数据格式。
2. 在 `niulai-mobile/release-history.json` 最上方添加发布日期、版本和用户看得懂的更新内容。不要把候选版本标为正式更新。
3. 构建并验证 Windows、macOS Apple Silicon、macOS Intel、Android 安装包，将它们先上传 GitHub 草稿 Release。核对签名、包内源码、版本、大小和 SHA-256。
4. 更新 `download-files.json` 和下载页，保留旧文件与历史入口。全部包准备好后才将 Release 公开。
5. `node prepare.mjs` 从同一份更新记录生成网页和软件读取的版本文件，并检查版本号与下载元数据是否齐全。更新 service worker 缓存版本。`updates.json` 禁止离线缓存。
6. 发布到 Cloudflare Pages 的 `niulai-muyu`，保留 Worker、路由、D1 绑定和上次部署；验证公开资源、下载范围请求、完整文件摘要和反馈接口。不要改动摄影站 `raaay-portfolio`。

电脑版启动后及持续运行每 6 小时检查一次；Android 打开/返回应用时检查，6 小时内自动检查合并。只有 `published` 状态、发布日期不晚于当前时间、版本高于已安装版本、下载地址为固定官网地址时才显示更新。手动检查显示状态，系统通知由开关和系统权限决定，同一版本成功提醒后不再重复。

未授予通知权限仍有软件内提示；断网保留已知更新并允许手动重试。应用不会自动下载安装，不上传股票、持仓、设备标识或联系人。旧安装包没有检查代码，必须先安装带有此能力的新版。
