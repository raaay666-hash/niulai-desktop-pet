# 牛来盯盘电脑版 1.5.0

## 主面板

左侧切换盯盘、自选、持仓与木鱼。盯盘页同时展示当前行情、牛来动作、当前持仓、最近报价和自选。

- 支持 A 股、港股、美股名称和代码搜索，自选最多 50 只。
- 持仓支持小数股，按标的原币计算今日和累计盈亏。
- 持仓金额默认隐藏，点击右上角眼睛按钮显示。
- 最近报价曲线记录本次运行获取的样本，最多 60 个。
- 设置提供浅色、深色和跟随系统外观，以及静音、标准、省电模式。
- 美股分别显示盘前、常规时段和盘后报价，报价时间标注美东时间。盘前涨跌比较上一常规收盘，盘后涨跌比较当日常规收盘。
- 今日盈亏包含该交易日的常规及延长时段变动。缺少计算所需基准价时显示破折号。

## 行情来源

在“设置 → 行情来源”选择公共行情，或接入自己的 HTTP JSON 报价接口。可按 A 股、港股、美股选择适用市场，设置股票代码格式、Bearer / 请求头 / 查询参数鉴权及请求间隔。接口地址支持 `{symbol}`、`{ticker}`、`{code}`、`{market}`、`{exchange}` 占位符。

默认字段为 `price`、`previousClose`、`change`、`changePercent`、`timestamp`、`session`、`symbol`、`name`。JSON 对象可位于指定路径，支持点路径、数组下标及 JSON Pointer。报价时间支持 Unix 秒或毫秒、带时区的 ISO 8601 和指定时区的日期。美股交易时段可返回 `pre`、`regular`、`post`。盘后接口可用 `regularPrice` 提供当日常规收盘价，`dayPreviousClose` 提供今日盈亏基准价。

“测试连接”展示解析后的价格、来源、时段和报价时间。“保存并使用”后所有窗口采用同一份数据。鉴权信息通过系统安全存储加密保存在本机。系统安全存储不可用时，配置仅在本次运行有效。可主动开启失败回退，界面会标明回退后的实际来源。搜索名称仍使用公共搜索接口。

报价是否过期依据对应报价时间判断。仅重新收到旧报价时，不会作为新成交样本触发提醒或哭泣。

## 桌面显示

三种窗口可以独立开关。

| 窗口 | 操作 |
| --- | --- |
| 桌宠 | 拖动牛身移动，单击互动，三连击触发不耐烦。顶部按钮打开主面板、收起或关闭。可切换成悬浮木鱼。 |
| 悬浮窗 | 显示行情或木鱼计数。拖动左侧手柄调整位置，点击行情区域展开，滚轮与左右按钮切换自选，展开后可在 10 秒自动收起。 |
| 卡片 | 切换桌宠、行情、持仓、休息四个场景。休息场景提供 20 秒计时。持仓遵循隐私开关。 |

关闭主面板会收起到托盘。双击托盘图标打开主面板，在托盘菜单或设置中退出程序。退出后停止行情刷新并关闭全部悬浮窗口。

窗口位置保存在本机。显示器变化时将窗口限制到可见工作区，也可使用“窗口归位”。锁屏与系统睡眠时隐藏悬浮窗口并暂停行情，解锁后恢复。

## 动作和木鱼

复用安卓版 15 组逐帧动画和 27 种状态。动作预览可逐项查看。电脑版为明显下跌的捂眼动作增加泪滴，并以捂眼哭泣代替明显下跌时的休息动作。

木鱼主面板、桌宠、悬浮窗和卡片共用本机计数。每次点击记一次，密集点击的动作最多保留一次后续敲击。新一轮只清零本轮，保留今日及累计。今日计数按电脑本地自然日更新。

## 下跌时播放妈妈音效

在“设置 → 桌宠”中开启“下跌时播放妈妈音效”。默认关闭，使用原版 `mama.mp3`。

- 日跌幅达到 −3%，连续两次成功获取的有效报价确认，间隔至少 5 秒后开始哭泣。
- 连续两次报价回到 −2.5% 以上，间隔至少 5 秒后结束哭泣。
- 启动、解锁、切换股票后的 30 秒暂停触发。
- 休市、断连和报价延迟时暂停触发。
- 声音在动作开始 1 秒后播放，300 毫秒渐入，音量为主音量的 20%。
- 单次哭泣只播放一次，整个程序至少间隔 15 分钟。冷却时间保存在本机。
- 报价恢复后再次跌破阈值才会重新触发。静音、安静办公、关闭动画、关闭自动动作或没有可见盯盘牛时保持安静。
- 多个窗口同时开启时，由其中一个可见窗口播放一次。

界面保留功能开关和已有音量控制，详细规则记录在本说明中。

## 提醒与记录

设置中的“提醒与记录”提供情绪记忆、收盘总结、安静办公，以及价格、涨跌幅、回到成本、累计盈亏和快速变化提醒。提醒作用于当前盯盘标的。盈亏金额使用标的原币。

## 本机数据与升级

首次升级读取旧版自选、选中股票、单持仓、音量、动画、隐私相关设置及提醒。旧版 3D 演出提醒改为 2D 动作。旧窗口位置用于桌宠。

新版共享数据写入 Electron 用户数据目录下的 `desktop-state-v2.json`。保存操作串行执行，通过临时文件替换。退出前等待写入完成。旧版 localStorage 数据继续保留，便于回退。

成本、股数、计数和设置保存在本机。查询词和股票代码发送给行情提供方。

公开行情可能延迟或中断。获取时间与接口提供的源时间分别标记。常规交易时段按周历估算，节假日与停牌情况需另行确认。盈亏未计交易费用，今日盈亏按当前持股数估算。
